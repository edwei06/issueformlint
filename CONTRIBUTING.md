# Contributing

Small, focused bug fixes and new validation rules are welcome.

1. Open an issue describing the GitHub form behavior, ideally with a minimal YAML example and a link to the relevant GitHub documentation.
2. Add or update a test for that behavior.
3. Run npm test, npm run check, and npm run selftest.
4. Submit a pull request that explains the behavior and any compatibility risk.

Keep validation offline and avoid reading outside the requested template directory. Do not add a rule based only on a guess about GitHub's preview schema.
